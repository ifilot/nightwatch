# Quick Menu reference-informed draft

An original two-pane design informed by the visual approach of COLOR042 and
COLOR043 from the user's extracted Quick Menu icon collection: full-canvas
window, strong black structure, bright working area and sparse text marks.
No reference bitmap pixels are copied into this asset.

This design is now the release icon at `../NIGHT.ICC` and `../NIGHT.PNG`.
The earlier Commander design remains at `../options/NIGHT1.ICC`.

- 32x32 pixels; fixed EGA palette; 4-bit indexed PNG.
- Binary transparency; 1,032-byte ICC with checked color/mask bitplanes.
- `preview.png` shows 6x and native 1x on blue, gray and black.
- Regenerate with `python3 tools/quickmenu_reference.py`.

Original Nightwatch artwork and generator: GPL-3.0-only.
