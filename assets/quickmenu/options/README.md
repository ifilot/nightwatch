# Five Quick Menu icon directions

Option 1, **Commander**, was the initial selection. The release icon at
`../NIGHT.ICC` now uses the later reference-informed variation. All five
original designs remain here for comparison.

1. **Commander** — file listings in two panes, with an active selection.
2. **Folder pair** — overlapping blue and yellow folders.
3. **NW badge** — a white/cyan monogram on a blue badge.
4. **File transfer** — two documents connected by a yellow arrow.
5. **Folder monogram** — a yellow folder carrying a blue N.

Each NIGHT1 through NIGHT5 pair contains a 32x32, 4-bit indexed EGA PNG and a
1,032-byte Quick Menu ICC file with binary transparency. All colors belong to
the fixed 16-color EGA palette. The candidates use between four and seven
opaque colors. ICC bitplanes and mask are checked by round-trip decoding.

`comparison.png` shows every design at 6x on gray and 1x on blue, gray and black.
It is a comparison sheet, not an icon to import. `ICONS.ZIP` contains all five
PNG/ICC pairs with DOS-compatible filenames.

Regenerate with `python3 tools/quickmenu_options.py` from the repository root.
