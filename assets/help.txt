Nightwatch is a two-pane file navigator for MS-DOS.
Use the keyboard to browse, view and manage your files.

#NAVIGATION
Tab                 Switch between the two panels.
Up / Down           Select the previous / next entry.
Home / End          Select the first / last entry.
PgUp / PgDn         Move through the directory a page at a time.
Enter               Open a directory or file; run a typed command.
Backspace           Go to parent if the command line is empty.
Ctrl-R              Refresh both panes and check free space.
F9                  Pick a drive for the active panel.
Arrows or a letter select; Enter opens its root; Esc cancels.
Choose "Enter a path..." or press . for a directory path.

#SELECTING FILES
Insert / Space      Mark or unmark the selected entry.
+ / -               Mark all entries / clear all marks.
Ctrl-F              Find a filename using a pattern.
Ctrl-P / Ctrl-N     Mark / unmark entries matching a pattern.
Patterns use * for any sequence and ? for one character.
Use marked entries, or the current entry if none are marked.

#FILE OPERATIONS
F5                  Copy files and directories.
F6                  Move or rename files and directories.
F7                  Create a directory.
F8                  Delete recursively, after confirmation.
Ctrl-U              Unpack selected ZIP/ARJ into the other pane.
Copy and move destinations must be absolute DOS paths.
For several marked entries, choose an existing directory.
Existing directories merge; existing files ask what to do.
O overwrites, S skips, and Esc cancels the operation.

#COPY PROGRESS AND CANCELLATION
Before copying, Nightwatch counts every file and its size,
including files in subfolders. Esc can cancel this scan.
The dialog shows completed / total files and skipped files,
current-file bytes, file progress and overall progress.
Skipped files also advance overall progress.
KiB/s shows the recent speed; time left is for the current file.
Speed and time show -- until a sample is available.
Esc cancels between transfer blocks or directory entries.
The unfinished copy is removed; completed files remain.
Timestamps and file attributes are preserved.

#ARCHIVE BROWSING
Enter on ZIP/ARJ opens a read-only folder view without unpacking.
Enter opens subfolders; Backspace or .. returns to the parent.
F3/Shift-F3 views one member; F5 extracts selected/marked entries.
Archive panes cannot be edited, deleted, moved or copied into.
Extract nested archives with F5 before opening them.

#ZIP AND ARJ EXTRACTION
Choose an existing destination directory. O overwrites, S skips.
Stored and DEFLATE ZIP entries work at all compression levels.
ARJ supports stored and methods 1-4; binary files only.
Names must fit ASCII DOS 8.3; unsafe paths are rejected.
CRC and sizes are checked before a file replaces the original.
ZIP64, encryption, split archives and Deflate64 are unsupported.
NW /unzip D:\PACK.ZIP D:\OUT extracts without overwriting.
NW /unarj D:\PACK.ARJ D:\OUT does the same for ARJ.
ARJ text mode, chapters, extended headers and SFX are excluded.

#VIEWING AND EDITING
F3                  Open the text viewer.
Shift-F3            Open the hex viewer.
F4                  Open the external editor.
In a viewer: arrows and PgUp/PgDn scroll; Home/End jump.
Viewer F4           Switch between text and hex views.
Viewer F7           Search for text or binary bytes.
Viewer F8           Find the next occurrence.
Viewer Ctrl-G       Go to a byte offset (decimal or 0x hex).
Search text directly, or use hex:DE AD 00 BE EF for bytes.
Esc closes the viewer and returns to the panels.

#TOOLS AND SETTINGS
F2                  Choose display mode; R toggles remembering it.
Ctrl-S              Choose the panel's sorting order.
Ctrl-O              Open a DOS shell; EXIT returns to Nightwatch.
Ctrl-W              Save mode, paths and sorting to NIGHT.CFG.
Ctrl-T              Storage tests: quick, long, verify, cleanup.
Storage tests keep manifests and logs on another drive.
After a safe unmount/reboot, verify the saved manifest.
Failed/cancelled test files remain available for inspection.
F1 / Alt-F1         Open Help / About.
F10                 Quit Nightwatch.
Type a command and press Enter to run it in DOS.

#DOS LIMITS
Names use DOS 8.3 format. Hidden and system files are shown.
Dates are displayed as MM-DD-YY.
Directory pages hold 512 entries; [MORE] means another page.
Archive panes retain their 512-entry [LIMIT] boundary.
Recursive operations include entries beyond this panel limit.
Operations support up to 32 nested levels and 127-byte paths.
A copy selection can contain up to 4,294,967,295 bytes.
Read-only files are preserved and cannot be deleted directly.

#More file tools
Enter on EXE, COM or BAT runs it in the active directory.
Alt-F7 searches beneath a directory, beyond the visible page.
Search: Enter opens a match's location; N continues; Esc stops.
Ctrl-A (or Alt-Enter) inspects and changes R/H/S/A attributes.
Ctrl-L calculates bytes in the selection, including folders.
Free space is sampled once per drive, shared by both panes.
Folder changes reuse it. Ctrl-R resamples (K = KiB).

#Large folders and input
Ctrl-PgDn / Ctrl-PgUp load the next / previous directory page.
Pages hold up to 512 entries; sorting and marks belong to a page.
[MORE] means another page exists. Archive panes retain [LIMIT].
Input: Left/Right, Home/End, Delete and Backspace edit in place.
Ctrl-Left/Right move by words. Tab completes a local filename.
Dialogs: Up/Down recall recent input. Ctrl-U clears the field.
Commands: Ctrl-E / Ctrl-X recall previous / next commands.
Up/Down also recall history while a command is being edited.

#Batch transfers
Conflicts show source and destination size and date.
O overwrites once; A overwrites all; S skips once; K skips all.
Transfer errors offer R retry file, S skip file, or Esc cancel.
Retry cleans partial staging first; completed files stay copied.
